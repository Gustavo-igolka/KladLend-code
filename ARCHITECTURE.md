# Архитектура KladLend / ASIM

## Структура скриптов

```text
scripts/
├── mechanics.sk                  # Общие механики, не принадлежащие одному персонажу
├── parkour/
│   ├── core.sk                   # Изоляция сессий, очистка этажей и жизненный цикл САП
│   ├── commands.sk               # Запуск, остановка и настройка площадки
│   └── generator.sk              # Детерминированная генерация трасс по ID
├── characters.sk                 # Реестр персонажей, GUI выбора и выдача наборов
├── characters/
│   ├── killers/
│   │   ├── denden.sk
│   │   ├── necromancer.sk
│   │   ├── anomaly.sk
│   │   ├── project.sk
│   │   ├── blind.sk
│   │   ├── samurai.sk
│   │   └── max.sk
│   └── survivors/
│       ├── solo.sk               # Андрей, Рататуй, Кирилл
│       ├── guards.sk             # Михуилонг, Илья, Dartikil, Маёр
│       └── support.sk            # МякШмяк, Томас, Саня, Детектив
├── round.sk                      # Жизненный цикл раунда, победа, LMS, Bloodlust
├── vision.sk                     # Интерфейс кулдаунов и виженов
├── levels.sk                     # Опыт и уровни
├── skins.sk                      # Скины и косметика
├── dummy.sk                      # Манекены для тестирования и взаимодействия
├── generators.sk                 # Генераторы
├── lockers.sk                    # Шкафы и бочки
├── event.sk                      # Ивенты
├── guide.sk                      # Внутриигровой справочник
├── setup.sk                      # Карты, точки, базовые настройки
└── ...                           # Остальные независимые системы
```

## Правила размещения кода

- `mechanics.sk` содержит только общие механики: систему кулдаунов, модификаторы восстановления, общую обработку урона и станов, общую скорость убийц и предметы карты.
- Уникальные способности, пассивки, состояния и сущности убийцы находятся в его собственном файле в `characters/killers/`.
- Способности выживших находятся в файле их класса в `characters/survivors/`.
- `characters.sk` остаётся центральным реестром выбора и выдачи наборов; реализации способностей там нет.
- ID персонажей и имена переменных при переносе не меняются.
- Остальные системные файлы не переносятся только потому, что обращаются к персонажам.

## Границы изменений

Макс реализован в `characters/killers/max.sk`; его выбор, стартовый набор, перезарядки, уровни и справочник интегрированы в системные файлы. После загрузки на сервере необходимы проверка синтаксиса Skript и игровой тест; серверное тестирование здесь не выполнялось.
